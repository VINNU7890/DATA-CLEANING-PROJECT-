# MySQL Data Cleaning Project

## Project Overview
This project focuses on cleaning and preparing a raw dataset using MySQL. The dataset contained duplicate records, null/blank values, inconsistent formatting, and unnecessary columns that needed to be fixed before analysis.

The goal of this project was to transform raw data into a clean, structured, and analysis-ready dataset using SQL queries.

---

## Tools & Technologies Used
- MySQL
- SQL

---

## Data Cleaning Tasks Performed
- Created a staging table
- Identified duplicate records
- Removed duplicate rows using ROW_NUMBER()
- Standardized inconsistent values
- Handled null and blank values
- Removed unnecessary columns
- Converted data into analysis-ready format

---

## SQL Concepts Used
- SELECT
- UPDATE
- DELETE
- ALTER TABLE
- ROW_NUMBER()
- PARTITION BY
- CTEs / Subqueries
- Data Standardization
- Filtering & Sorting

---

## Project Outcome
The final cleaned dataset became more reliable, consistent, and ready for exploratory data analysis, dashboard creation, and reporting.
